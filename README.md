# 🚀 AI-Powered Portfolio Website

A modern full-stack developer portfolio website built using React, Vite, Node.js, Express, and MongoDB.

This portfolio showcases projects, certifications, skills, and includes an integrated chatbot as well as contact system.

---

## ✨ Features

- Modern responsive UI
- Animated sections
- Project showcase section
- Skills section
- Certificate section
- Contact form integration
- Chatbot support
- MongoDB database integration
- Cloudinary image uploads
- REST API backend
- Fully responsive design

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer

- CORS

```bash

npm run dev
```

---

## Backend Setup

